三步开工

先确认连接通道，再给三个键和一个旋钮配动作，最后验证一次真实触发。

1

连接并确认通道

插入 2.4G 接收器或让设备进入蓝牙配对。自动检测会优先使用接收器；也可在上方选择“仅蓝牙 / 仅 2.4G”。

2

配三键一旋钮

点设备图上的键位，选择手势与动作。内置一套官方推荐映射，进来就能用。

3

验证触发

用“监听模式”按一次设备按键，页面会显示收到的 HID 报文，确认设备与配置都对上了。

跨域受限时，请使用文件或粘贴方式。
导入规则
  • 必须有 id、name、version、permissions 四个字段。
  • 权限只能取 input / clipboard / network / filesystem，超出即拒绝。
  • 同名不同版本会提示覆盖，不会静默替换。
  • 未签名的包只能本地试用，不能发布到市场。

已知限制
  • 写入走厂商通道：report ID 0x55、TEA 加密、64 字节明文，与 Studio 用的通道一致；必须选到 usage page 0xFFFC 的接口，标准键盘接口写不了。
  • 设备端只有 6 个键槽（键 1/2/3、旋钮按下、左右旋转），每槽最多 4 个键码；双击、长按、文本与应用类动作只能由 Agent 执行。
  • 媒体键用系统页（类型 0x03），取值范围官方未公开；写完会读回校验，不支持就标失败，不会写坏原配置。
  • 写操作是"写后读回"验证，失败只影响该槽位。
