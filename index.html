三步开工

先确认连接通道，再给三个键和一个旋钮配动作，最后验证一次真实触发。

1

连接并确认通道

插入 2.4G 接收器或让设备进入蓝牙配对。自动检测会优先使用接收器；也可在上方选择“仅蓝牙 / 仅 2.4G”。

2

配三键一旋钮

点设备图上的键位，选择手势与动作。内置一套官方推荐映射，进来就能用。

3

验证触发

用“监听模式”按一次设备按键，页面会显示收到的 HID 报文，确认设备与配置都对上了。

插件导入

支持三种来源：插件包 JSON、分享链接、粘贴清单。导入前会展示权限，确认后才落地。

跨域受限时，请使用文件或粘贴方式。
导入规则
  • 必须有 id、name、version、permissions 四个字段。
  • 权限只能取 input / clipboard / network / filesystem，超出即拒绝。
  • 同名不同版本会提示覆盖，不会静默替换。
  • 未签名的包只能本地试用，不能发布到市场。
